# أفق | دفتر التجارب

منصة عربية للاقتباسات تحوّل الفكرة إلى تجربة صغيرة. يستطيع الزائر تصفح الاقتباسات والبحث عنها دون حساب، بينما يتطلب نشر اقتباس إنشاء حساب أو تسجيل الدخول. يختار الكاتب لون البطاقة من خمس لوحات مع معاينة مباشرة. وتضيف «سلسلة الأثر» خطوة مرتبطة باقتباس وموعدًا بعد 24 ساعة ثم تسجيل النتيجة مع خيار المشاركة دون اسم.

## المتطلبات

- PHP 8.3 أو أحدث مع امتدادات Laravel ومنها `pdo_sqlite` و`mbstring` و`fileinfo` و`openssl`.
- Composer 2.
- Node.js 22 أو أحدث وnpm.

## التشغيل على Windows

افتح PowerShell داخل مجلد المشروع ثم نفّذ:

```powershell
Copy-Item .env.example .env
composer install
php artisan key:generate
if (-not (Test-Path database\database.sqlite)) { New-Item -ItemType File database\database.sqlite }
php artisan migrate --seed
npm ci
npm run build
php artisan serve
```

افتح `http://127.0.0.1:8000`. ينشئ الأمر `migrate --seed` ثلاثة اقتباسات تجريبية. لا ترفع ملف `.env` أو قاعدة بياناتك المحلية ضمن ملفات التسليم.

## جعل حسابك مالك الموقع

1. حدّد البريد الذي ستستخدمه لحساب المالك.
2. قبل نشر الموقع، ضع البريد نفسه في `OWNER_EMAIL` في إعدادات بيئة الاستضافة. في التشغيل المحلي، اكتبه في `.env` ثم نفّذ `php artisan config:clear`.
3. أنشئ حسابًا بهذا البريد من صفحة التسجيل أو استخدم الحساب الموجود به. سيظهر رابط «لوحة المالك» لهذا الحساب المطابق فقط، ويرفض الخادم الحسابات الأخرى.
4. تعرض اللوحة عدد الحسابات المسجلة وأسماءها وبريدها وتاريخ التسجيل وآخر دخول وعدد مرات الدخول. لا تُجمع هوية زوار التصفح دون حساب؛ لذلك لا يمكن معرفة من تصفح الموقع كزائر.

لا تضعي كلمة مرور أو مفتاح استضافة داخل هذا الملف أو في مستودع GitHub. اضبطي `OWNER_EMAIL` كمتغير بيئة في المنصة عند النشر.

## أهم المسارات

- `/` الصفحة العامة والبحث؛ يستطيع الزائر التصفح دون حساب.
- `/signup` إنشاء حساب، ثم العودة إلى الصفحة العامة.
- `/login` و`POST /logout` الدخول والخروج.
- نشر اقتباس أو تعديله يتطلب حسابًا؛ التعديل والحذف لصاحب الاقتباس فقط.
- `/my-impact` دفتر خطوات الأثر والنتائج.
- `/owner` لوحة خاصة بالحساب الذي يطابق `OWNER_EMAIL`.

## قواعد الخصوصية والصلاحيات

- تحفظ كلمات المرور بتجزئة Laravel.
- تتحقق الخوادم من صلاحيات ملكية الاقتباس والخطوة.
- لا تعرض قصص الأثر اسم صاحب الخطة، ولا تظهر إلا إذا اختار المشاركة بعد تسجيل النتيجة.
- تسجّل لوحة المالك إحصاءات الحسابات المسجلة ووقت دخولها فقط؛ لا تتعقب هوية الضيوف.
- يرفق كل نموذج برمز حماية CSRF، وتتحقق الخوادم من حدود المدخلات والصلاحيات.

## طريقة العرض والتسليم

أضف الاسم والرقم الجامعي إلى مستندات المشروع إذا طلبت منصة المادة ذلك. استبدل الاقتباسات التجريبية باقتباسات تختارها وتوثّق مصادرها، وراجع خطوات العرض حتى تستطيع شرح الحسابات والبيانات والصلاحيات وسلسلة الأثر.

سيناريو فيديو مدته دقيقة: تصفح المكتبة والبحث، إنشاء حساب، نشر اقتباس بلون تختارينه، بدء خطوة، ثم تسجيل نتيجتها. ارفعي الفيديو إلى Drive والصقي رابط المشاهدة في مكان التسليم إن كان مطلوبًا.

## رابط عام عبر HTTPS

رابط `127.0.0.1` محلي ولا يمكن للآخرين فتحه. للنشر العام تحتاجين حساب استضافة ومستودع Git متصلًا بها، وقاعدة بيانات دائمة، وضبط `APP_KEY` و`APP_URL` و`OWNER_EMAIL` ومتغيرات قاعدة البيانات. يدعم Laravel Cloud استيراد مستودع Laravel ونطاق `laravel.cloud` مع SSL/TLS؛ يمنح الحساب الجديد رصيد استخدام بقيمة 5 دولارات لمدة 14 يومًا، ثم يكون Starter حسب الاستخدام، لذلك راجعي التكلفة قبل النشر. راجعي صفحة الأسعار الرسمية: https://marketing.cloud.laravel.com/pricing

لا تستخدمي SQLite المحلية لموقع عام متعدد الحسابات. بعد إعداد الاستضافة ونشر التطبيق، انسخي رابط HTTPS الذي تمنحه المنصة وقدميه مع ملفات SRS وERD وZIP إذا طلبته منصة المادة.
